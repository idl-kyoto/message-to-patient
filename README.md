# Message to Patient

医師が決めた内容を、患者さん向けの書面にするアプリです。実行時にClaudeを呼びません。外部通信もありません。

Built with Claude: Japan 2026 の提出物です。

## これは何か

診療で患者さんに伝える説明を、医師自身が作った文章で、書面にするツールです。

- 診断から文章作成、書面の承認まで、すべての過程を医師が決定します
- 項目を選ぶと、あらかじめ作っておいた「文章モジュール」が組み立てられ、書面になります
- 承認した書面だけを、印刷できます
- 文章モジュールにない特別な内容も、患者さんごとに書き加えられるので、一人ひとりに合わせた書面になります

## なぜ作ったか

医師として40年以上、診療の現場で、患者さんに説明を重ねてきました。口頭での説明に加え、パンフレットを渡したり、手書きで個別の説明を書いたりもしますが、それだけでは、患者さんが十分に理解して、治療を続けられるとは限りません。たとえば、ケガのあとに付けた固定具（添え木）を、自己判断で外してしまう方もいます。本来は、一人ひとりに合わせた手作りの説明が必要ですが、診療時間も医療資源も限られるなか、そこまでの時間は取れないのが現実です。

このツールで、患者さんは、手作りの個別の説明を受け取れます。医師は、説明にかける時間を減らし、その分の医療資源を、診療のほかの部分に使えます。

これは、AI（Claude）の助けがあって、はじめて現実的になりました。医師の話を整理して、変数、選択肢、文章の形にまとめる作業に、Claudeの力を使いました。当然ながら、診断も、治療も、内容も、承認も、医師が決めます。

ベテランの説明の仕方を、本人が現場にいるうちに、次の人が受け継げる形にする、という願いもあります。

## 医師とClaudeの役割

**医師が行うこと**

- 診断と治療
- 説明の文章モジュールの作成と、最終の文言の決定
- 患者さんに合わせた項目の選択
- 書面の承認

**Claudeが行うこと（作成と開発の段階だけ）**

- 医師の話を整理して、文章モジュールにまとめる補助
- 開発での、設計の相談とコードの作成

**Claudeが行わないこと**

- 診断、治療の判断、文章の言い換えや書き足し
- 実行時の処理（アプリは、実行時にClaudeを呼びません。書面の組み立てと点検は、アプリ内のルールが行います）

## 仕組み

- 書面の文は、医師が決めた文章モジュールと、医師が書き足す特別指示と、毎回必ず出る外せない注意書きだけです。言い換えはありません
- 変数（固定、入浴など）と、その選択肢の数は、疾患ごとに医師が自由に決められます
- すべての変数で、必ず選びます。変数ごとに、1つだけ選ぶ形と、複数選べる形があります。複数選べる変数でも、1つ以上選びます。何も出さないときは、医師が作った「該当なし」を選びます。「該当なし」は、ほかの選択肢と同時には選べません
- 選んだ選択肢の文が空欄のときは、選択肢の名前が、そのまま書面に印刷されます。文を書けば、その文が印刷されます
- 印刷の前に、アプリ内のルールで点検します。次の場合は、印刷が止まります
  - 選び忘れがある
  - 外せない注意書きが欠けている
  - 連絡先が未設定である（仮の表記も、未設定として扱います）
- 医師が決める警告ルールの仕組みもあります。現在、ルールは入っていません
- 特別指示は、患者さんごとに書き加える欄です。保存しません。書面に特別指示があるときは、点検欄に表示され、印刷のときに確認の画面が出ます
- 「外せない注意書き」は、どの病気にも合う一般的な文で、毎回必ず書面に出ます。本文は、編集も削除もできません。連絡先だけ、医療機関ごとに設定します
- 文章モジュールは、医師が画面で編集できます。編集した文章モジュールと連絡先は、ブラウザ内に保存されます
- 名前欄はありません。選択内容も書面も保存しません
- 外部通信はありません。実行時に、Claudeや他のサービスを呼びません

## 対応している疾患

- 足首の捻挫（急性期、骨折のないもの）：固定、荷重、下肢挙上、入浴、仕事、運動などを、患者さんに合わせて選べます
- 骨粗鬆症の運動処方箋：運動能力、行う運動、セット数を、患者さんに合わせて選べます
- 白紙データ（data/blank.json）：2階が、新しい疾患を作る土台として読み込みます

## 動かし方

- このフォルダで、python3 -m http.server 8765 を実行します
- Safari で http://localhost:8765/index.html を開きます
- 足首の捻挫は index.html（既定）、骨粗鬆症の運動処方箋は index.html?d=osteoporosis-exercise です

## 2階（データを表で作る画面）

- editor.html を、直接開きます（index.html に入口はありません）
- 表のマスをクリックして、下の編集欄で名前や文を入力します
- 「例を見る（骨粗鬆症）」で、骨粗鬆症のデータを読み込みます
- 「1階で書面を作る」で、1階に移ります
- 「データを書き出す」で、データをファイルにします

## 印刷（Safari）

- 書面の長さは、選んだ項目や特別指示の文字数で変わります。内容が多いと、2枚以上になります
- 1枚にしたいときは、選ぶ項目や文字数を工夫してください
- 「ヘッダとフッタをプリント」を外すと、余白が増えます。確認した書面では、これだけで1枚に収まりました
- 縮小して収めたいときは、「用紙サイズに合わせる」も使えます

## Claudeの使い方

- 作成の段階：医師の話を聞いて、変数、選択肢、文章モジュールに整理する補助にClaudeを使いました
- 分からない点は、推測せず、必ず医師に質問します。医学の内容は、医師が答えたことだけを使い、Claudeが補うことはしません
- 実行時：Claudeは使いません。組み立てと点検は、アプリ内のルールで動きます
- 開発：設計の相談はClaudeとの対話で、実装はClaude Codeで進めました

## AI利用表示

このアプリは、Claude（Anthropic）と医師の共同作業で作りました。コードはClaude Codeが書き、医学の内容と文は医師が決めました。実行時にClaudeは呼びません。詳しくは docs/開発の記録.md にあります。

- 文章モジュールは、Claudeが医師の話を整理して文章にまとめる補助をし、その後、医師が内容と最終の文言を決定・承認しました
- 医学的な判断は、Claudeも、アプリも、行いません

## 持ち込みデータ

文章モジュールは、医師本人が作成したオリジナル内容に基づきます。元は、医師本人が自分の診療所のホームページに載せた文章で、このハッカソンのキックオフ前のものです。その文章を、Claudeを使って文章モジュールに分け、医師が診療の現場の言葉に直して、決定・承認しました。足首の文は、キックオフ後に作りました。骨粗鬆症の運動処方箋は、医師の診療経験をもとに、期間中に決めました。個人情報は含みません。

## 文章の素材

ガイドラインは、材料として使いました。書面は、医師の臨床経験をまとめたもので、診療ガイドラインそのものではありません。診断と治療の判断は、すべて医師が行います。

## 注意

- 診断から治療まで、すべて一貫して医師が行います。このツールは、診断や治療の判断をすることはありません
- デモでは、架空の症例だけを使います。実際の患者さんの情報は使いません
- 連絡先は、医療機関ごとに設定します。未設定のままだと、印刷が止まります
- 書面には、毎回必ず、次の注意書きが印刷されます。「これは一般的な目安です。治り方や期間には個人差があり、例外もあります。担当医の指示を優先してください。」
