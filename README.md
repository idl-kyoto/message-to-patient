# Message to Patient

## 解く問題

口頭の説明だけでは、患者さんに伝わりにくいです。
既製のパンフレットは画一的で、その人に合いません。

## 作るもの

医師が項目を選ぶと、あらかじめ用意された部品文が並び、患者さん向けの書面になります。

- 書面の文は言い換えません。部品文をそのまま使います。
- Claudeの役割は、部品文を並べて組み立てることと、医師が直した後の点検に限ります。
- 医療の判断は、Claudeにさせません。

## 持ち込みデータ

部品文は、このハッカソンのキックオフ前に、開発者本人（医師）が用意しました。
自分の診療所のホームページに載せた自分の文章をもとに、診察室で患者さんに話す言葉に書き直したものです。

コードは、キックオフ後に新しく作ります。

## 個人情報

- 書面に名前の欄は作りません。
- 選択記録も書面も保存しません。

開発中です（2026年11月）。
