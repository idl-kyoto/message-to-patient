# Message to Patient

医師が決めた内容を、患者さん向けの書面にするアプリです。実行時にClaudeを呼びません。外部通信もありません。

## 動かし方

- このフォルダで、python3 -m http.server 8765 を実行します
- Safari で http://localhost:8765/index.html を開きます

## 疾患データ

- 足首の捻挫：index.html（既定）
- 骨粗鬆症の運動処方箋：index.html?d=osteoporosis-exercise
- 白紙データ：data/blank.json（2階が読み込みます）

## 2階（データを表で作る画面）

- editor.html を、直接開きます（index.html に入口はありません）
- 表のマスをクリックして、下の編集欄で名前や文を入力します
- 「例を見る（骨粗鬆症）」で、骨粗鬆症のデータを読み込みます
- 「1階で書面を作る」で、1階に移ります
- 「データを書き出す」で、データをファイルにします

## 印刷（Safari）

- 書面の長さは、選んだ項目や特別指示の文字数で変わります。内容が多いと、2枚以上になります
- 1枚にしたいときは、選ぶ項目や文字数を工夫してください
- 「ヘッダとフッタをプリント」を外すと、余白が増えます。確認した書面では、これだけで1枚に収まりました
- 縮小して収めたいときは、「用紙サイズに合わせる」も使えます

## テスト

node test/check.js

足首用と共通用の両方を、順に実行します。

## 文章の素材

ガイドラインは、材料として使いました。書面は、医師の臨床経験をまとめたもので、診療ガイドラインそのものではありません。診断と治療の判断は、すべて医師が行います。

## AI利用表示

このアプリは、Claude（Anthropic）と医師の共同作業で作りました。コードはClaude Codeが書き、医学の内容と文は医師が決めました。実行時にClaudeは呼びません。詳しくは docs/開発の記録.md にあります。
